How to get started

  1. Download the appTap Install the app. A file called ATSYS-Parent.apk downloads to your phone.
  2. Allow the installAndroid may ask you to allow installs from your browser. Tap Settings, switch Allow on, then go back. This is normal for apps outside Play Store. Only install from the link your child's teacher sent.
  3. Open it. You're in.Come back to this page and tap Open in ATSYS Parent. Your code is filled in for you.

Excuse lettersSend a reason and a photo. See the answer.
